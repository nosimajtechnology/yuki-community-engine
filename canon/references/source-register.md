## Verification labels

- **Verified canon:** directly supported by Tier 1 or directly inspectable Tier 2 material.
- **Official identity, access-limited:** attributable to an official surface but direct content inspection was technically blocked; state the limitation.
- **Community convention:** recurring public practice that may guide format or tone but cannot change canon.
- **Creative interpretation:** original material created for a scene; never cite it as project history.

## Update procedure

For every new source, record its URL or file path, date inspected, tier, exact claim supported, and limitations. If a Tier 2 source conflicts with the Tier 1 turnaround on visual identity, pause and request team resolution rather than silently choosing.

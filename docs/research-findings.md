# Research findings — founding pass

Date: 2026-08-26

## Verified or attributable

- The user-supplied five-view turnaround is sufficient to define Yuki's visual identity and is installed as Tier 1.
- Y2K Dotcom's official web and social surfaces identify the ecosystem around Y2K Dotcom, Yuki/YUKI.EXE, Y2Kverse, nostalgia culture, and “the Renaissance.”
- Current indexed YUKI.EXE profile copy describes the account as “just a 2000s kid.”
- A public Y2K DOTCOM X community exists and uses “Welcome to the Renaissance” language.

## Community convention

- Current third-party campaign listings request original, dynamic Yuki edits and explicitly value effort beyond low-effort single-prompt output.
- Creative contests and paid short-form campaigns indicate active community remixing, but do not define character or world canon.

## Unconfirmed or superseded

- Older indexed copies describe Yuki as born from the Y2K bug and leading a nostalgic renaissance. Because current profile language appears changed and X blocked direct inspection in this environment, v1 excludes this from active canon.

## Access limitations

- The official website was reachable but produced no extractable text in the browsing environment.
- Direct X profile fetches returned access errors. Current search indexing and profile mirrors were used only with explicit access-limit labels.
- No exact official brand palette, vector logo, behavioral guide, or biography was supplied.

## Implementation consequence

v1 confidently locks visual construction while keeping biography and most fictional world details open. This is intentional: uncertainty is represented, not papered over with plausible lore.

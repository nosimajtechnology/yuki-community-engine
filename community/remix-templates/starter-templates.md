# Community remix templates

These templates expose the portable community workflow, not undocumented Nosimaj internal methods.

## Canon portrait

```text
Use the Yuki Community Engine in CHARACTER mode.
Create a clean [framing] portrait with [expression/pose].
Keep the signature outfit and bundled canonical turnaround as absolute authority.
Background: [simple color/environment].
```

## Everyday scene

```text
Use the Yuki Community Engine in SCENE mode.
Yuki is [one ordinary action] in [place/time].
The mood is [mood]. Use [one or two] historically grounded Y2K-era anchors.
No invented biography or dialogue.
```

## Absurd scene

```text
Use the Yuki Community Engine in STILL mode.
Treat this impossible premise with complete sincerity: [premise].
Keep one readable action and protect Yuki's canonical silhouette.
Label the premise as creative interpretation.
```

## Short cinematic

```text
Use the Yuki Community Engine in CLASSIC CINEMATIC mode.
Premise: [one continuous event].
Hook: begin [mid-action / with reveal / environment first].
Target: [duration, aspect ratio, provider if known].
Avoid repeated angles, dialogue, and continuity resets.
Start with the genesis frame and wait for approval.
```

## Episode

```text
Use the Yuki Community Engine in EPISODE mode.
Episode spine: [problem → escalation → turn → payoff].
Format: four progressive storyboards; use a fifth only if justified.
Create Storyboard 1 — Hook + Setup only, then wait for approval.
```

## Meme

```text
Use the Yuki Community Engine in MEME mode.
Format/reference: [recognizable situation, not another character's identity].
Visual joke: [simple contradiction or escalation].
Caption: [optional; keep separate from image generation].
```

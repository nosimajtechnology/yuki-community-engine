# Historical grounding protocol

Use this protocol when the user asks for recognizable 1998–2005 hardware, interfaces, fashion, retail, media, or environments.

## Research order

1. Search official manuals, manufacturer archives, catalogs, press photos, museum collections, archived retail pages, or period screenshots.
2. Confirm the object's release window and regional availability.
3. Inspect at least two views or sources when shape/layout fidelity matters.
4. Record only the features visible in sources: materials, proportions, control layout, connectors, interface resolution, signage, furniture, and lighting.
5. Use generic period vocabulary if reliable product-specific evidence is unavailable.

## Brief labels

- **Historically grounded:** supported by cited period or authoritative reference.
- **Era-plausible composite:** combines verified period features without copying one product.
- **Retro-futurist interpretation:** intentionally imagines how the millennium future felt; not historical reconstruction.

## Common failures

- modern flat-panel screens, smartphones, wireless earbuds, LED strips, contemporary gaming chairs, USB-C, or current UI patterns appearing in a period scene;
- every device rendered translucent or chrome;
- unreadable pseudo-brand text treated as a historical logo;
- using a modern nostalgia recreation as the only source;
- confusing late-2000s social-media design with 1998–2003 web design.

When exact fidelity is not central to the concept, use one or two grounded anchors and keep the rest generic.
